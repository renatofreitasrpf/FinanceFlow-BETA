# FinanceFlow

> Seu dinheiro, suas decisões, seu controle.

Aplicação web de controle financeiro pessoal desenvolvida com React, TypeScript e Tailwind CSS.

## Sobre o projeto

O FinanceFlow tem como objetivo oferecer uma interface intuitiva para acompanhar receitas, despesas e saldo financeiro, facilitando a organização e a visualização das finanças pessoais.

## Tecnologias
- React
- TypeScript
- Vite
- Tailwind CSS

## Status

Em desenvolvimento.

## Funcionalidades planejadas

- Dashboard financeiro
- Cadastro, edição e exclusão de transações
- Gerenciamento de categorias
- Filtros e pesquisas
- Gráficos e relatórios
- Persistência local de dados
